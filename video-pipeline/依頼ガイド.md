# 飲食店紹介動画 依頼ガイド

TikTok・Instagram リール用の縦型動画（1080×1920、9:16）を作るときに、Claude に渡すものと頼み方をまとめたもの。

---

## 1. 送るもの

### 必須
| もの | 内容 |
|---|---|
| 写真・動画 | 5〜10カット分。縦向きで撮ったもの。iPhone の写真（HEIC）・動画（HDR）のままで OK |
| 店舗情報 | 店名、エリア・最寄り駅、Googleマップ／食べログ／公式サイトの URL かスクショ |
| 自分の感想 | 何を食べた・飲んだか、良かったところ、誰におすすめか（テロップと投稿文の元になる） |
| PR かどうか | PR 案件なら投稿文に「PR」を入れる |

### あるとよいもの
| もの | 内容 |
|---|---|
| 並び順 | 送った順で使ってほしいなら「この順番で」 |
| 動きの指定 | 「基本は横スライド、ドリンクだけアップ」など |
| テロップの字体 | ゴシック（白太字＋黒縁）か明朝（白＋影）。指定がなければゴシック |
| 長さ | 指定がなければ 9〜15秒（1カット約1秒） |
| 営業時間・定休日・価格帯 | 投稿文に入れる場合 |

### 送り方
- 会話に直接添付する
- または Google ドライブのフォルダに入れて、リンクを送る（「リンクを知っている全員」が閲覧できる設定にする）

---

## 2. 撮影のコツ

- **縦で撮る**。リールの画面は縦 9:16 で、iPhone の写真（縦 3:4）よりも細長い。そのため、どの瞬間も写真の横幅の 6 割ほどしか映らない
- **主役は真ん中に**、上下左右に少し余白を残す
- **2〜3秒の短い動画を 2〜3本混ぜる**のが理想。持ち上げる・すくう・浸す・注ぐ・乾杯などの「動き」は写真では出せない
- **他のお客さんの顔、Wi-Fi のパスワード、レシートなどの写り込み**に注意。写っていたらこちらでぼかすが、最初から避けられるとよい
- 他人が撮った写真や、口コミサイトの点数・評価は使わない

---

## 3. AI で写真を拡張してから送る場合

写真の外側を AI に描き足してもらう方法（生成拡張・アウトペイント）。Photoshop の生成拡張、Canva のマジック拡張、ChatGPT や Gemini の画像編集などで使える。

### サイズ
| 使い方 | 比率 | サイズ（px） | 伸ばす方向 |
|---|---|---|---|
| アップ・ズーム・固定 | 9:16 | **2160×3840** | 上下 |
| 横スライド | 約5:6 | **3240×3840** | 左右 |

仕上がり（1080×1920）の 2 倍の大きさにしておくと、ズームしても画質が落ちない。

### 主役を置く範囲（2160×3840 の場合）
TikTok・リールでは、画面の下にキャプション、右にいいねボタンなどが重なる。次の余白を空けて、**横 120〜1860px・縦 500〜2540px の範囲**に主役を置く。
- 上：約500px
- 下：約1300px
- 右：約300px
- 左：約120px

一般的な目安で、アプリの画面は変わることがある。

### プロンプト例（そのままコピーして使える）
```
この写真を縦長に拡張してください。
- 出力サイズ: 2160×3840 px（縦9:16）
- 元の写真の部分（料理・飲み物・店内・看板・文字）は一切変えない。描き足すのは外側の背景だけ
- 描き足す部分は、元の写真に写っているテーブル・壁・床の続きにする
- 新しい料理・人・文字・ロゴは追加しない
- 主役（例：アイスラテのグラス）は、上から500px・下から1300px・右から300px・左から120pxの余白より内側に収める
```
横スライド用は、サイズを「3240×3840 px」、伸ばす方向を「左右」に変える。

### 注意
- 生成 AI で描き足した画像を使ったら、**投稿に AI ラベルを付ける**
- 料理・お店そのものは変えさせない。AI が勝手にメニューや値札を作ることがあるので、仕上がりを必ず確認する
- AI を使いたくない写真は、「写真全体を真ん中に置いて、上下を同じ写真のぼかしで埋める」見せ方も追加できる（まだ未実装。AI ラベル不要）

## 4. 調整の頼み方

Claude が「各写真のどこが映っているか」の確認画像を出す（緑の枠＝カットの始まり、オレンジの枠＝終わり、灰色の帯＝テロップの位置）。それを見て、番号と言葉で伝えれば OK。数字の指定は要らない。

| 直したいこと | 言い方の例 |
|---|---|
| 映る位置 | 「1枚目、スコーンが見えるようにもっと上」「3枚目はサンドを真ん中に」 |
| アップの強さ | 「5枚目はアップを弱く」「2枚目はアップなし」 |
| スライドの動き | 「1枚目は動きを小さく」「4枚目は逆向きに」 |
| 必ず入れたいもの | 「1枚目は COFFEE. の文字を最後まで全部見せたい」 |
| テロップとの重なり | 「4枚目、テロップがお客さんにかぶるからずらして」 |
| テロップの文言 | 「3枚目は『〇〇』に変えて」 |

## 5. 依頼テンプレート（コピーして埋める）

```
【動画作成の依頼】
■ 素材：（添付 または Google ドライブのリンク）
■ 並び順：送った順 ／ おまかせ
■ 動き：（例：基本は横スライド、ドリンクだけアップ）／ おまかせ
■ 店名：
■ エリア・最寄り駅：
■ 店舗情報の URL：（Googleマップ／食べログ／公式）
■ 食べた・飲んだもの：
■ 感想（良かったところ・誰におすすめか）：
■ PR：あり ／ なし
■ テロップの字体：ゴシック ／ 明朝 ／ おまかせ
■ 長さ：おまかせ ／ 〇秒くらい
■ AI で拡張した写真：あり（〇枚目）／ なし
```

---

## 6. 作業の流れ

1. 素材と上のテンプレートを送る（人）
2. 店舗情報の確認リストを出す（Claude）→ 確認する（人）
3. 台本（並び順・動き・テロップ）と確認画像を出す（Claude）→ 直したいところを伝える（人）
4. 動画を書き出す。投稿文・ハッシュタグも作る（Claude）
5. 最終確認をして、BGM をアプリで選んで投稿する（人）。Instagram は「高画質でアップロード」を ON にする

```bash
apt-get install -y fonts-noto-cjk fonts-noto-cjk-extra   # 日本語フォント

pip install faster-whisper                                # 参考動画の文字起こしをするときだけ

# 映る範囲の確認画像
python3 video-pipeline/make_video.py <project.yaml> --media <素材フォルダ> --preview preview.jpg
# 動画の書き出し
python3 video-pipeline/make_video.py <project.yaml> --media <素材フォルダ> --out output.mp4
```

台本の書き方は `video-pipeline/projects/` の例（`cafe_roasted/project.yaml` など）と README を参照。
