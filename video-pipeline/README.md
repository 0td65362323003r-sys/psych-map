# 飲食店紹介動画 自動作成パイプライン

写真（＋短い動画クリップ）と店舗情報から、Instagramリール用の縦型動画をAIだけで作る。
人がやるのは「素材を送る」「店舗情報の確認」「最終確認と投稿」の3つだけ。

## 決定事項

### 全体の流れ
1. 素材を送る（人）：写真・短い動画（元データ、縦向き）、店舗情報（Googleマップ/食べログ/公式のURL・スクショ・コピペ）、自分の感想、PRかどうか
2. 店舗情報を整理して確認リストを出す（Claude）→ 人が確認
3. 台本・テロップ・投稿文・ハッシュタグを作る（Claude）＋ 口コミとの類似チェック
4. 動きをつける（FFmpeg。ズーム・パンは事前に拡大してガタつき防止）
5. 組み立てて書き出す（FFmpeg。1080x1920 / 30fps / 高ビットレート / Noto Sans JP）
6. 人が確認してInstagramに手動投稿（BGMはInstagramアプリで選ぶ、「高画質でアップロード」をON）

### 口コミの扱い
- 文章ではなくポイントだけ抽出し、複数の口コミの傾向としてまとめる
- 毎回ゼロから自分の言葉で書く。元の文の言い換えはしない
- 投稿者本人の実体験を最優先
- 完成台本と参照口コミの長いフレーズ一致を自動チェック（短い一般表現は対象外）
- 他人が撮った写真、点数・評価は使わない
- PR案件は投稿文に「PR」、AI生成映像を使ったらAIラベル

### 参考動画1本目の分析結果（麻布十番のパフェ×ワインのリール、約13.7秒）
- 実写動画が中心（乾杯、スプーンですくう、手で持ち上げる）。写真だけではこの動きは出せない
  → 方針：写真＋スマホで撮った2〜3秒の短い動画を混ぜる
- カット約12個、1カット約1秒
- 構成：フック（乾杯＋一言）→ 2秒目に店名ロゴカード → 店内 → 席 → ワイン → パフェ寄り → すくう → 冒頭と同じ乾杯で締めてループ
- テロップ：一つの文をカットごとに区切って次のカットへ続ける。白太字ゴシック＋黒縁、中央、画面上から3〜4割の位置、1〜2行
- 音：BGMのみ、ナレーションなし（faster-whisper で確認済み。発話区間ゼロ）
- カット切り替えは音楽の区切りに合わせている可能性あり
- テロップ：「2軒目で来たら喜ばれる極上夜パフェ。」→「麻布十番駅からすぐ。」＋店名ロゴ →「実力派シェフが仕掛ける、」→「こだわり抜かれたアートパフェ。」

### 参考動画2本目の分析結果（池袋のつけ麺のリール、約18秒）
- 実写動画のみ。料理の全景 → 麺を持ち上げる → 厨房で店主が麺を茹でる・水で締める・盛り付ける → 全景 → つけ汁をれんげですくう → 麺を持ち上げる → つけ汁に浸す → 浸した麺を持ち上げる → チャーシューを浸す → サイドの丼（炙りチャーマヨ丼）をすくう
- カット約16個、1カット約1.1秒（1本目とほぼ同じテンポ）
- 構成：フック（料理全景＋「地名＋ジャンル＋断言」）→ 行列・作り手（店主の調理風景）→ 素材のこだわり → つけ汁 → 食べる動作の連続 → サブメニューで締め。ロゴカードなし、ループ構成でもない
- テロップ（1つの文をカットごとに区切って次のカットへ続ける、は1本目と同じ）：
  「池袋でつけ麺なら絶対ここ」→「開店してからずっと行列」→「北海道産小麦を使った麺は香り高くて」→「濃厚つけ汁と相性抜群」→「麺をつけ汁に絡めたら」→「箸が止まらなくなる…」→「柔らかいチャーシューも絶品で」→「炙りチャーマヨ丼も食べるべき」
- テロップの見た目：白の明朝体（細め）＋影、中央、画面上から約45〜50%の位置、ほぼ1行。1本目（白太字ゴシック＋黒縁）とは別スタイル
- 音：BGMのみ、ナレーションなし（faster-whisper で確認済み）。約5.6〜6.5秒で音が途切れる区間あり（BGMのブレイクか、画面録画由来かは不明）。約8.3秒・約12.9秒で曲の展開が変わり、カットの切り替えとほぼ一致
- 「食べる動作（持ち上げる・浸す・すくう）」の寄りが全体の半分以上。写真ではなく短い動画素材がやはり必須

### 2本から見えた共通パターン
- 1カット約1秒、ナレーションなし（BGM＋テロップのみ）
- 冒頭テロップで「誰に・どこで・何が」を言い切るフック
- 1つの文をカットごとに分割して読ませる（文末を「〜て」「〜たら」でつなぎ、次のカットへ引っ張る）
- 中盤に「作り手・店の雰囲気」、後半に「食べる動作の寄り」
- テロップのフォント・装飾はアカウントごとの個性（ゴシック太字＋黒縁 or 明朝＋影）。テンプレートで切り替えられるようにする

## スクリプト
- `analyze_reference.sh <動画ファイル>`：メタ情報、カット検出、コマ切り出し、一覧画像、スペクトログラム、文字起こし（faster-whisper small。初回は huggingface.co からモデルをダウンロード）
- `ref_analysis/`：参考動画2本の分析結果（メタ情報・カット秒・音量・文字起こし・コマ一覧画像）。元動画・音声・コマ単体は容量が大きいのでコミットしていない
