# くるみ ヒアリングフォーム

胡桃さんに1問ずつ答えてもらうフォームです。「送信して次へ」を押すたびに、回答がGoogleスプレッドシートの「回答」シートに自動で保存されます。

- 「38問中 1問目」のように、1画面に1問だけ表示
- 選択式・複数選択・自由記入に対応（選択式には任意の補足欄つき）
- 未入力のままでは送信できない（全問回答が必須）
- 書きかけの文章はブラウザに一時保存されるので、途中で閉じても消えない
- 次に開くと、まだ答えていない質問から再開
- 全問回答すると完了画面になり、一覧からどの質問でも修正できる

## スプレッドシートの列

| 列 | 内容 |
|---|---|
| A | No |
| B | セクション |
| C | 質問 |
| D | 回答（読みやすい形） |
| E | 状態（未回答／回答済み） |
| F | 最終更新 |
| G | 入力データ（システム用・非表示） |

## 設置手順（10分ほど）

1. Googleドライブで新しいスプレッドシートを作る（例：「くるみ ヒアリング回答」）
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初からある `コード.gs` の中身をすべて消し、`Code.gs` の内容を貼り付ける
4. 左の「ファイル」の「＋」→「HTML」で `index` という名前のファイルを作り、`index.html` の内容を貼り付ける
5. 上のプルダウンで `setup` を選んで「実行」する
   - 初回は権限の確認画面が出るので、自分のアカウントで許可する
   - スプレッドシートに「回答」シートができ、38問が並ぶ
6. 右上の「デプロイ」→「新しいデプロイ」
   - 種類：ウェブアプリ
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
7. 表示されたウェブアプリのURLを胡桃さんにLINEで送る

URLを知っている人は誰でも回答できるので、URLは胡桃さんにだけ共有してください。

## 質問を変えたいとき

`Code.gs` の `QUESTIONS` を書き換えて `setup` をもう一度実行し、「デプロイを管理」から新しいバージョンとしてデプロイし直します。
質問の並び順を変えると、すでに保存された回答とずれるので、回答が始まる前に変更してください。
